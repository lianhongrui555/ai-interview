# 熔炉对决

《熔炉对决》是一款桌面浏览器炼金卡牌对战游戏。玩家在双路双桥战场部署单位，通过“主体＋词缀”随机熔铸创造一次性融合卡，并在三场分支路线中收集卡牌和临时祝福。

## 当前内容

- 三战分支路线：第一层二选一、第二层二选一、第三层固定首领。
- 每局普通节点随机获得一项隐藏特殊规则，进入战斗后揭晓。
- 14 张永久收藏、三套牌组预设、开局解锁 8 张。
- 第一张素材决定融合主体，第二张决定固定词缀。
- 普通、稀有共鸣、招牌三级融合结果；同组合和稀有度属性固定。
- 六组指定招牌配方，以及任意组合可触发的通用传奇机制。
- 拖曳部署、暂停、1×/2× 倍速、卡牌详情和部署预览。
- 五步新手教程，正常完成时间约 90～120 秒。
- 自由练习场：全卡临时牌组、无限圣水、计时开关和四档 AI。
- 三星目标、临时祝福、节点永久星级和 V1 存档自动迁移。
- 原创 WebAudio 芯片音乐与音效。

## 操作方式

1. 按住手牌移动超过 8 像素开始拖动，拖到合法区域松手部署。
2. 单击卡牌查看属性，`Esc` 或右键可以取消当前操作。
3. 点击“熔铸工坊”，第一张选择主体，第二张选择词缀。
4. 确认后生成隐藏稀有度的融合卡，再把结果卡拖到战场。
5. 催化剂拖到熔铸工坊区域后，会修改下一次融合概率。
6. 先摧毁守卫塔，再攻击国王塔；时间结束比较皇冠。

## 本地开发

```powershell
npm install
npm run dev
```

开发地址为 `http://127.0.0.1:5173/alchemy-arena/`。

## 测试与构建

```powershell
npm test
npm run test:e2e
npm run build
```

`npm run build` 输出到 `dist/`。

## 素材

正式透明 PNG 放在 `public/assets/cards/` 或 `public/assets/towers/`，再更新 `src/assets/manifest.ts`。未登记图片会自动使用代码绘制的临时素材。
