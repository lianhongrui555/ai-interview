# 正式素材放置说明

当前游戏默认使用代码生成的临时像素图。收到正式透明 PNG 后，将文件放入以下目录：

- `public/assets/cards/`：单位、建筑、法术、陷阱和催化剂图片。
- `public/assets/towers/`：四类塔图片。

然后在 `src/assets/manifest.ts` 中填写键名与文件名。键名必须与 `src/data/cards.ts` 的 `artKey` 或塔贴图键一致。

推荐规格：

- 单位、建筑、陷阱：64×64，透明背景，角色居中，无烘焙阴影。
- 塔：96×96，透明背景，底座居中。
- 卡面：正式版可另做 256×320，目前卡牌界面会自动放大小图。
- 像素缩放使用整数倍，线条避免半透明抗锯齿。
